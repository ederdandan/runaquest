Como Jogar

          
Monte um programa com blocos e veja seu guardião executar.

        

        
      


      

        

          1
          
Objetivo: acender todas as runas 💠 (os altares circulares azuis) da ilha. O contador 💠 no topo mostra quantas faltam.

        

        

          2
          
Monte o programa: toque nos comandos para colocá-los em ordem na caixa MAIN. Nada acontece até você apertar ▶ EXECUTAR.

        

        

          3
          

            
Os comandos:

            
    
              
  • ⬆️ Avançar — anda 1 laje para onde o guardião olha (a seta amarela no chão).
    • 
              
  • ↰ ↱ Girar — vira 90° para a esquerda/direita do guardião, sem sair do lugar.
    • 
              
  • 🦘 Saltar — sobe ou desce exatamente 1 degrau. Em piso plano, use Avançar.
    • 
              
  • 💠 Ativar Runa — acende a runa onde o guardião está. Ativar de novo apaga!
    • 
              
  • ⚡ 🔮 P1 / P2 — executam tudo o que estiver dentro da caixa P1 / P2 (funções).
    • 
            

          

        

        

          4
          
Funções P1/P2: toque na caixa P1 para selecioná-la (fica com borda verde) e os novos blocos vão para lá. Depois coloque ⚡ P1 no MAIN para usá-la quantas vezes quiser.

        

        

          5
          
Errou? O bloco com problema treme em vermelho. Toque nele para removê-lo, ou use ⏭ Passo para ver o programa um comando por vez. 💡 Dica: a 1ª é grátis; as seguintes colocam o próximo bloco certo por 25 🪙.

        

        

          ⭐
          
Estrelas: use poucos blocos para ganhar 3⭐ (a meta aparece embaixo dos blocos). Qualquer solução conta para avançar!

        

        

          Teclado: ↑ avançar • ← → girar • Espaço saltar • A ativar •
          1 2 P1/P2 • Backspace apagar • Enter executar • Esc fechar
